## 6回目の授業

### (課題) kind を使ってローカル環境で k8s を動作させる

```bash
1. 下準備として、docker の registory を変更

レジストリミラーにmirror.gcr.ioを設定してDocker Hubのレートリミットに備える

# Docker Engineに以下のコードを追加
{
  "registry-mirrors": [
    "https://mirror.gcr.io"
  ]
}

# 設定の確認をするコマンド
$ docker system info

## 出力結果が以下のようになっていればOK
Client: Docker Engine - Community
 Version:    28.0.1
 Context:    default
#中略
 Registry Mirrors:
  https://mirror.gcr.io/
```

```bash
2. kindのセットアップ

# aquaを使えるようにする手順

# brewでインストール
brew install aquaproj/aqua/aqua

# PATHを通す
export PATH="${AQUA_ROOT_DIR:-${XDG_DATA_HOME:-$HOME/.local/share}/aquaproj-aqua}/bin:$PATH"

# 設定をシェル上で反映
source ~/.zshrc


# kindを
# サーバー構築のリポジトリのディレクトリに移動しておく
aqua init

# aqua g -i を実行するとツールを選択する画面が出てくるので `kind` と入力し `kubernetes-sigs/kind` を選択する
aqua g -i

#　追加したツールを使えるようにする
aqua i -l

# インストールされていることを確認
kind version
```

```bash
3. kind で latest の k8s をインストールする

# cluster.yaml ファイルを手動で作成

# cluster.yaml ファイル内に以下を記述する
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
- role: control-plane
- role: control-plane
- role: control-plane
- role: worker
- role: worker
- role: worker

# config を指定して cluster を作成
kind create cluster --config cluster.yaml

# aqua で kubectl と k9s を使えるように
aqua g -i

# いろいろ出てくるので kubernetes/kubernetes/kubectl と derailed/k9s を選択

#　追加したツールを使えるようにする
aqua i -l

# k8s の node 一覧を表示
kubectl get nodes
```
```bash
4. k8sでwebアプリケーションが動作することを確認する

# 今回はnginxを動作させる
# helm は aqua で helm/helm を選択して入れる

# Helm のリポジトリを追加
helm repo add bitnami https://charts.bitnami.com/bitnami
helm repo update

# Helm chart を k8s クラスタに適用
helm install kdg-server-nginx bitnami/nginx

# ブラウザから nginx にアクセスできるようにポートフォワードする
kubectl port-forward service/kdg-server-nginx 8080:80

# ブラウザ上のlocalhost:8080で動作確認する
```
