### (課題) wordpress が動く compose ファイルに対応する manifest を書く

```bash
1. aqua で kustomize を入れる
```
```bash
2. 
# ビルドしてクラスタに適用
kustomize build . |kubectl apply -f -

# クラスタに展開したサービスにアクセス出来るようにする
kubectl port-forward service/wordpress 8080:8080

# ブラウザで http://localhost:8080/ にアクセスし wordpress の画面が出てくれば成功
```
