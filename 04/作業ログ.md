### 今回の課題
```bash
(概要)
docker compose で wordpress と DB のコンテナを動作させる

(詳細)
imageとしては以下の2つを使用する。
・wordpress
・mariadb


必要な記述として以下の点を考慮する。
・services で コンテナ名と対応する image を指定する。
・volumes で wordpress のデータとmariadbのデータを保存するような volume を指定する
・パスワードを環境変数に設定する
・今回は本番環境で動かさず検証のみなので environment に直接パスワードを書いても良い
```

```bash
version: '3.8'

# コンテナを定義
services:
  wordpress:
    image: wordpress:latest
    container_name: wordpress
    depends_on:
      - db
    ports:
      - "8080:80"
    environment:
      WORDPRESS_DB_HOST: db
      WORDPRESS_DB_USER: wordpress
      WORDPRESS_DB_PASSWORD: examplepassword
      WORDPRESS_DB_NAME: wordpress
    volumes:
      - wordpress_data:/var/www/html

  db:
    image: mariadb:latest
    container_name: mariadb
    environment:
      MYSQL_ROOT_PASSWORD: rootpassword
      MYSQL_DATABASE: wordpress
      MYSQL_USER: wordpress
      MYSQL_PASSWORD: examplepassword
    volumes:
      - mariadb_data:/var/lib/mysql

# それぞれ永続化ボリュームに保存
volumes:
  wordpress_data:
  mariadb_data:
```

```bash
# コンテナを起動するコマンド
docker-compose up -d
```
