```bash
# hadolintのインストール
# (方法)homebrew or VSCodeの拡張機能

# インストールコマンド
brew install hadolint

# バージョン確認
hadolint -v
```

### hadolintでリントして前回作ったDockerfileを改善する
```bash
# Dockerfileをリントするコマンド
hadolint Dockerfile

# 今回リントで引っかかったエラー内容
Dockerfile:2 DL3045 warning: `COPY` to a relative destination without `WORKDIR` set.

# ↑は WORKDIR を設定せずに相対宛先にコピーするとエラーが発生しやすいため、改善することを求めている。

# 解決時に参考にした記事 (https://deepsource.com/directory/docker/issues/DOK-W1006)

# 今回の場合、以下で解決する

FROM golang:alpine
WORKDIR /"作業ディレクトリを指定"
COPY main.go .
RUN go build main.go
CMD ["./main"]

```

### マルチステートビルドとは
```bash

# Dockerfile内で複数のステージ（段階）を使ってイメージを構築する方法。これにより、不要なファイルやツールを最終的な実行イメージに含めず、軽量でセキュアなコンテナを作成できる。

# 今回の場合

# ① ビルドステージ
FROM golang:1.24-alpine3.22 AS builder

WORKDIR /
COPY main.go .
RUN go build main.go

# ② 実行ステージ（成果物だけを含む超軽量イメージ）
FROM alpine:3.22

# 前のステージから必要なファイルだけコピーしてる
COPY --from=builder /main /
CMD ["/main"]
```
